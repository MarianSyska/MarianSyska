## Featured Projects

### [Crioulo](https://github.com/MarianSyska/Crioulo) — C++20 OpenGL Rendering Library
A modern 3D rendering engine built from scratch. Implements Cook-Torrance PBR, C++20 Concepts for compile-time vertex validation, RAII resource management, Uniform Buffer Objects, and skybox rendering.

`C++20` `OpenGL` `PBR` `CMake` `RAII`

---

### [Retinal-Disease-Detection](https://github.com/MarianSyska/Retinal-Disease-Detection) — PyTorch Medical Imaging
Multi-task classification for retinal diseases using ResNet18/50. Predicts diabetic retinopathy grade and edema risk from fundus images. Includes focal loss, class-weight balancing, and hyperparameter grid search.

`PyTorch` `Computer Vision` `Transfer Learning` `Focal Loss`

---

### [MLib](https://github.com/MarianSyska/MLib) — Neural Network Library from Scratch
Educational MLP implementation using only NumPy. Manual backpropagation, Xavier initialization, and modular architecture mirroring PyTorch's API. Includes comparison with equivalent PyTorch implementation.

`NumPy` `Backpropagation` `Deep Learning` `From Scratch`

---

### [Portfolio-WebApp](https://github.com/MarianSyska/Portfolio-WebApp) — Django/Wagtail Portfolio
Personal portfolio and CV website with CMS admin, responsive Bootstrap 5 design, SCSS, and GitHub Actions CI/CD to DigitalOcean.

`Django` `Wagtail` `Bootstrap 5` `CI/CD` `Nginx`
